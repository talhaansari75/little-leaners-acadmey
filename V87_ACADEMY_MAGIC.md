# V87 Academy Magic

Adds a richer, colourful Academy presentation while preserving the three class pathways:

- Nursery
- KG
- Montessori

New UI systems include daily class missions, Magic Rooms, virtual learning buddy selection, Magic School Bus, expanded Trophy Garden, and quick links for Art, Music, Stories, Science, Feelings, and Nature.

No KG-1 or KG-2 pathway is introduced. Existing class-specific curriculum remains separated.
