# V80 Preschool Upgrade

Added to the preschool learning experience:

- My Little World: persistent local avatar and room decorations unlocked by XP.
- Music World: offline Web Audio piano keys and offline-friendly rhythm/rhyme prompts.
- Mini Game Arcade: bird/bigger/matching rounds with kid-friendly feedback.
- Expanded child navigation inside the Advanced Preschool Hub.
- Existing 100 local animal pictures, 20 local animal/bird sound effects, 12 word pictures, and story illustrations remain bundled.

## Offline note
All listed local images and WAV animal sounds are bundled. Music uses Web Audio synthesis, so it requires no network. Spoken narration continues to use the device/browser speech engine and can vary by device.
